# Single File Uploader

## Steps to run

### Installation

Run `npm i` to install all dependencies, including Express, Multer, Path, and Ejs.

### Running

Run `npm start` the start the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### Uploading

Click the file uploader and select a file from your system. Press 'Upload' to send it to the server. The file will now display in the Uploaded Files section.

### Deleting

Select an item from the Delete File dropdown list and press the 'Delete' button. The file will now be removed from the server.
